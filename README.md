# 🛒 Technical Store - MERN Stack E-Commerce Platform

**Technical Store** is a fully functional, Full-Stack e-commerce web application specializing in tech gadgets (Mobiles & Laptops). Built using the **MERN Stack**, this platform provides a seamless, secure, and responsive shopping experience from product discovery to checkout and order tracking.

---

## 🚀 Key Features

* **🔐 Secure Authentication:** Users can register a new account or log in securely to protect their personal data and active shopping sessions.
* **📱 Smart Product Browsing:** Products are organized into dedicated categories (Mobiles and Laptops) for easy navigation.
* **🛒 Dynamic Cart Management:** Users can add products to their cart directly from the home page, adjust quantities, or remove items within the dedicated Cart page accessible from the Navbar.
* **💳 Structured Checkout Process:** A specialized Checkout page allows users to confirm their purchases and provide accurate delivery address details.
* **📦 Order History (My Orders):** A dedicated section where logged-in users can review all their past orders and track their purchase history linked to their specific account.

---

## 🛠️ Tech Stack

### **Frontend**
* **React.js & Next.js** - For building a fast, interactive, and optimized user interface.
* **Tailwind CSS** - For modern, clean, and fully responsive UI styling across all screen sizes.

### **Backend**
* **Node.js & Express.js** - For building a robust RESTful API and handling server-side logic.
* **MongoDB** - A flexible NoSQL database used to store users, products, and order records.

## ⚙️ Installation & Local Setup

Follow these steps to get the project running locally on your machine:

### 1. Clone the Repository
```bash
git clone [https://github.com/ratepnaal/e-commerce-MERN-Stack.git](https://github.com/ratepnaal/e-commerce-MERN-Stack.git)
cd e-commerce-MERN-Stack
```

### 2. Backend Setup
1. Navigate to the backend directory:
```bash
   cd backend
   ```
2. Install the dependencies:
```bash
   npm install
   ```
3. Create a `.env` file in the root of the backend directory and configure your environment variables (e.g., `MONGODB_URI`, `JWT_SECRET`, etc.).
4. Start the server:
```bash
   npm start
   ```

### 3. Frontend Setup
1. Navigate to the frontend directory:
```bash
   cd ../frontend
   ```
2. Install the dependencies:
```bash
   npm install
   ```
3. Start the development server:
```bash
   npm run dev
   ```
